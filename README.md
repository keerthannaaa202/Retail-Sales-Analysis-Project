# 📊 Retail Superstore Sales Analysis

An end-to-end data analytics project analyzing retail sales performance using **Python, SQL, and Power BI** — from raw data to business insights.

## 🎯 Objective
Which regions, categories, and products drive the most revenue — and where is there untapped potential?

## 🛠️ Tools Used
- **Python (Pandas)** – Data cleaning & exploratory data analysis
- **SQL (MySQL)** – Aggregation queries: GROUP BY, ORDER BY, subqueries, distinct counts
- **Power BI** – Interactive dashboard with KPI cards, slicers, and linked visuals

## 📁 Dataset
Sample Superstore dataset — 9,789 order-level records (2015–2018), sourced from Kaggle.

## 🔄 Workflow
Raw CSV → Python cleaning (Pandas) → Cleaned CSV → SQL analysis + Power BI dashboard


## 📈 Key Metrics
| Metric | Value |
|---|---|
| Total Sales | $2.25M |
| Total Orders | 4,916 |
| Total Customers | 793 |
| Date Range | 2015 – 2018 |

## 💡 Key Insights
- **West & East** regions generate ~2/3 of total sales — **South** has the biggest growth opportunity
- **Technology** is the top revenue category, led by high-value items like copiers and video-conferencing systems
- **Consumer** segment contributes ~51% of total revenue
- Sales grew **~50% from 2016 to 2018** — strong upward trend
